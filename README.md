# 🎬 Smart Semantic Video Transcription System

## 📌 Overview
Smart Semantic Video Transcription System is an AI-powered application that converts videos into intelligent transcripts.  
Unlike normal subtitle generators, this project not only converts speech into text but also understands the **meaning, emotions, and actions happening in the video**.

---

## 🚀 Features

- 🎤 Original Speech-to-Text Transcription
- 🧠 Semantic Transcription (Meaning-Based)
- 😡 Emotion Detection
- 🎬 Video Action Description
- 🌍 Multi-language Translation
- ⏱ Timestamped Subtitles
- 🔍 Smart Video Search
- 🔗 Video Similarity Detection

---
